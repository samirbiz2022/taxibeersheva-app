# TaxiBeerSheva — הורדה

אפליקציית ניהול והפצת נסיעות של **מוניות העיר באר שבע**.

> אדל • תהילה • נשאת ונתת באמונה

## הורדה לאנדרואיד

את הקובץ להורדה תמצאו תחת [Releases](../../releases/latest).

### התקנה
1. הורידו את הקובץ `TaxiBeerSheva.apk` מהטלפון.
2. אנדרואיד יבקש אישור להתקנה ממקור חיצוני — אשרו.
3. בפתיחה הראשונה האפליקציה תבקש **כתובת שרת** ו**קוד גישה** — תקבלו אותם מההנהלה.

### אייפון
באייפון אין התקנת קובץ. פותחים את כתובת השרת בספארי → כפתור שיתוף → **"הוסף למסך הבית"**.
